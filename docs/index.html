What this is

The Fermi Gamma-ray Burst Monitor locates a burst by comparing counts across its twelve NaI detectors, whose responses point in different directions. This project re-runs that calculation independently on archival data for 2,049 bursts, twice each: once using the catalog's full T90 interval as the source window, and once using only the brightest sub-interval, the way a human Burst Advocate would.

Measured against the 284 bursts with an independent arcsecond position, the reproduction is as accurate as the official pipeline — closer to the truth on 48% of them, which is a coin flip. Separation from the official map turns out to measure agreement with Fermi, not accuracy.

Reproducing it

The scripts are in the repository root. fetch_catalog.py pulls the burst catalog from HEASARC, download_gbm.py retrieves trigger data and official sky maps (5.2 GB, not in this repository), run_all.py and extract_contours.py do the localization, and the build_*.py scripts render these pages. Everything reads public NASA archival data.

Built from the Fermi GBM burst catalog, Fermi LAT and Swift catalogs at HEASARC. Localization by legacy_DoL from astro-gdt-fermi.
